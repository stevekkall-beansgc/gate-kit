# Security Policy

## Reporting a vulnerability

GitHub private vulnerability reporting is enabled for this repository. Please report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/stevekkall-beansgc/gate-kit/security/advisories/new). Do not disclose vulnerability details in a public issue.

Include the affected branch or release, a concise reproduction, expected impact, and any relevant logs or proof-of-concept details.

## Supported versions

Security fixes are supported for the current `main` branch and the latest release.

## Scope and limitations

This policy covers vulnerabilities in gate-kit's own source code, workflows, tests, examples, and documentation. It does not cover separate caller repositories, qa-kit, BeanFit, runner images, or third-party services; report issues in those projects to their maintainers.
